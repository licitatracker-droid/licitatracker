Gestão de Empresas
Cadastro e configuração de clientes
📌
A tela de Empresas é acessível apenas pelo administrador no menu principal.
1

Acesse 🏢 Empresas no menu

Visível apenas para o perfil Admin.

2

Clique em + Nova Empresa

Preencha Nome, CNPJ, Responsável, Telefone, E-mail e Observação.

3

Selecione os módulos

Marque quais módulos a empresa pode acessar: Diário, Favoritos, Conta Corrente, Analytics, Config.

4

Vincule os produtos

Selecione os produtos que esta empresa pode ver no Diário e Favoritos.

5

Crie o primeiro usuário

Preencha Nome, E-mail, Perfil (Admin/Viewer) e Senha. O usuário já poderá fazer login.

👥
Gerenciar Usuários
Adicionar, desativar e redefinir senhas
1

Abra o card da empresa → botão 👥 Usuários

Lista todos os usuários da empresa com status e permissões.

2

Adicione novos usuários

No formulário inferior, preencha Nome, E-mail, Perfil e Senha. Clique em ➕ Adicionar Usuário.

3

Redefina senha (🔑)

Clique no ícone de chave ao lado do usuário para definir uma nova senha via prompt.

4

Ative/Desative (⛔ / ✅)

Clique no ícone ao lado do usuário para suspender ou reativar o acesso sem excluir o registro.

🔐
Permissões por Usuário
Override individual sobre os módulos da empresa
💡
Cada usuário herda as permissões da empresa. Você pode sobrepor individualmente clicando nos módulos de cada usuário.
EstadoSignificado
↑ herda ONEmpresa permite, usuário herda — módulo ATIVO
↑ herda OFFEmpresa não permite, usuário herda — módulo INATIVO
✅ ONForçado ativo para este usuário (independente da empresa)
❌ OFFForçado inativo para este usuário (independente da empresa)
⚠️
Clique no módulo para ciclar entre os estados: herda → força ON → força OFF → herda.
📦
Produtos por Empresa
Restrição de visibilidade por produto
📌
Fonte única: produtos são cadastrados em ⚙️ Config → Produtos e depois vinculados a cada empresa.
1

Cadastre o produto em Config

⚙️ Config → seção Produtos → digite o nome → clique em + Adicionar.

2

Edite a empresa → Produtos Vinculados

Selecione o produto no dropdown e clique em + Adicionar.

3

O usuário só verá o produto vinculado

No Diário, Favoritos e Analytics, apenas editais com aquele produto serão exibidos.

✅
Nenhum produto vinculado = empresa vê todos os produtos.
⚙️
Configurações do Sistema
Produtos, portais, unidades e clientes

📦 Produtos

Cadastre os nomes dos produtos monitorados (ex: Café, Palestra). São usados em todo o sistema.

🌐 Portais / Sites

Cadastre os portais de compras (ex: BLL, Compras.gov.br) para uso nos filtros e links.

📏 Unidades

Cadastre as unidades de medida usadas nos itens dos editais (ex: KG, UN, PC-500g).

👤 Clientes

Lista de clientes para referência interna e geração de boletins.

Gestão de Cargas
Controle dos dados importados do PNCP
🚨
Apagar uma carga remove permanentemente os registros de pncp_publicacoes daquele período. Favoritos e contratos não são afetados.
1

Acesse ⚙️ Config → seção Gestão de Cargas

Lista todas as datas com quantidade de registros carregados.

2

Apague um dia específico

Clique em 🗑 Apagar ao lado da data desejada e confirme.

3

Ou apague um período

Use os campos De/Até e clique em 🗑 Apagar Período para remover múltiplos dias.

4

Reprocesse via extrator Python

Após apagar, rode o extrator novamente para reimportar o período com os dados corretos.

⚠️
Também é possível apagar diretamente no Supabase com: DELETE FROM pncp_publicacoes WHERE data_carga BETWEEN '2026-05-01 00:00:00' AND '2026-05-02 00:00:00'
✏️
Inserção Manual de Editais
Editais de portais externos ao PNCP
💡
O botão ✏️ Inserir Manual fica no canto superior direito do Diário — visível apenas para o perfil Admin.
1

Clique em ✏️ Inserir Manual

O botão fica no topo direito do Diário.

2

Preencha os dados

Objeto, Nº Compra/Pregão, Data, Hora, Órgão, Modalidade, UF e Link do Portal.

3

Adicione o item principal

Selecione Produto, Unidade, Nº Item, Qtd e Vlr Ref.

4

Anexe documentos

Suba o PDF do edital e cole o link direto na seção 📎 Anexos.

5

Salve ou Salve e Favorite

O edital recebe número automático MANUAL-2026-001 e aparece no Diário misturado com os demais.
